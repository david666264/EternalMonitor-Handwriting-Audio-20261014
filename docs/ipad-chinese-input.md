# iPad 中文界面与原生输入

此修改版基于 EternalMonitor 0.3.0，沿用原版协议和应用标识，兼容现有电脑端。保留 USB 画面、手写与电脑声音同时播放。

连接后打开底部「键盘」，使用系统原生文本框编辑草稿。拼音候选、系统手写、选择、粘贴、撤销和删除均由 iPadOS 文本编辑器处理。键盘不再限制为英文。

1. 先点电脑画面中需要输入的文本框。
2. 在 iPad 草稿框里输入，用键盘地球图标切换中文拼音或手写。
3. 选好候选词并修改完毕后，点「输入到电脑」。它不会额外按回车。
4. 确实需要提交电脑输入框时，使用「输入并回车」。下方「电脑回车」也会直接向电脑发送按键。

未确认的拼音组合不会传到电脑。草稿会自动保存到 iPad 本机，收起键盘、断线重连或重新启动应用后仍可继续编辑。连接暂不可用时不发送。

提交前会先在本机保存一份「上次提交」备份，再把文字交给传输通道并清空当前草稿。若电脑没有完整收到文字，重新连接后打开键盘，点「恢复上次提交」找回文字；恢复仅把文字放回草稿，必须再次点击「输入到电脑」才会发送。草稿非空时恢复按钮不可用，避免覆盖正在写的内容。只保留最近一次提交，不是完整的历史记录。

应用重新启动、打开键盘或恢复备份都不会自动重发。重新提交前，请先检查电脑输入框已收到多少内容，避免产生重复文字。应用只能确认文字已交给现有传输通道，不能确认电脑端哪个输入框接收到了文字。草稿和提交备份保存在应用私有目录，卸载应用或删除其数据会一并移除。

如果地球图标没有中文选项，请在 iPad「设置 → 通用 → 键盘 → 键盘 → 添加新键盘」添加中文拼音或手写。应用不能代替系统安装输入法。

远程 Ctrl、Alt、Win、Tab、方向键和退格仍在快捷键栏。草稿非空时，系统键盘退格只编辑本地草稿；单独的「电脑退格」直接作用于电脑。提交中文前会释放已按下的远程修饰键，避免误触电脑快捷键。

## 安装与验证

下载未签名 arm64 IPA，用自己的有效证书和描述文件签名后安装；最低 iPadOS 17。更新覆盖前请保留原签名标识，以便继续使用既有配对和偏好。

macOS 流程编译真机归档并运行原生文本编辑单测、中文界面与输入 UI 测试，以及既有 Wi-Fi/USB 手写和声音回归。模拟器的 `setMarkedText` 验证组合文本边界；真实拼音候选、随手写体验、签名后安装及实际 USB 连接仍需 iPad 验收。

长文回归加入现有 `ChineseInputTests`，不依赖模拟器安装中文键盘。测试通过原生编辑菜单粘贴 1,254 字符、包含中文、表情和 48 处换行的合成文本，点「输入到电脑」，逐条核对真实主机的 UTF-16 输入日志，检查应用仍在前台、连接未退出、没有丢字、重复或额外的末尾回车。另以强制终止、重新启动验证未提交草稿持久恢复，以及提交备份只在手动点击后恢复到草稿、不会自行发送。测试日志只使用此合成文本。

该 UI 测试的传输是 Wi-Fi 回环夹具，不冒充 iPad 真机 USB 测试。USB 长文问题还需由 FramedLink 传输回归及真机 USB 验收分别验证。使用已配置 Xcode 和依赖的 macOS，可运行：

```sh
bash scripts/test_ios.sh -only-testing:EternalMonitorUITests/ChineseInputTests
```

`self-sign-ipa.yml` 的中文输入任务已选择该测试类，新增用例会随同运行；测试定义本身不表示本次构建已通过，结果以对应工作流和保留的证据为准。
